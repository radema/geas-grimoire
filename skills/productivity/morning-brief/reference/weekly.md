# Weekly plan/review (deferred)

A weekly plan/review, written to a hand-edited `week-YYYY-Www.md` file, is a
later-stage feature. It is not built in this pass — this skill only produces
the daily `brief-YYYY-MM-DD.md` and `commitments-YYYY-MM-DD.json`. There is
no logic for the weekly file anywhere in this skill; when that feature is
built, it will get its own reference doc and its own step in SKILL.md rather
than being bolted onto the daily flow.
