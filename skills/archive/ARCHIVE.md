# Archived skills

This category holds retired skills: ones no longer installed at `~/.claude/skills/` but worth
keeping around.

It is currently empty. A skill lands here when it is dropped from the live set but still has
value for reference or possible revival.

Third-party skills are never archived here — they are deleted outright and credited in the
README instead. 23 unmodified third-party skills were removed on 2026-09-19 (14 GitHub Spec Kit,
9 other imports).
